# 周报演示指南

本指南使用虚构项目和合成工作记录，展示文字生成、自动审核、人工修订、版本管理和 Markdown 下载。它是操作说明，不代表新增了一轮真实模型验收；已执行的验证范围见[功能状态与验证记录](progress.md)。

## 演示前准备

按[运行与验证](running.md)安装并启动前后端，按[配置说明](configuration.md)配置文本模型；图片演示额外需要支持图片输入的视觉模型。健康检查通过后，还需实际创建并启动任务才能验证模型调用。

在本地新建的空数据环境演示，配置文件、密钥、任务数据库、图片、日志及生成结果都保留在本地。下列内容可直接输入，不需要恢复个人历史案例。

## 1. 创建文字周报

打开 `/tasks/create`，在“项目名称 / 周报名称”填写：

```text
示例项目：研发看板｜演示周报
```

在“项目背景与碎片化工作记录”填写：

```text
以下是虚构项目的演示材料，不涉及真实客户或业务数据。
本周完成：登录接口开发和接口测试；看板筛选交互评审。
进行中：报表页面与后端接口联调，目前尚未完成。
风险与阻塞：共享测试环境不可用，报表联调受阻。
下周计划：测试环境恢复后继续报表联调，并补充联调测试记录。
待确认事项：测试环境恢复时间尚未确定；负责人尚未确定。
不要推测完成比例、日期、负责人或额外成果。
```

不上传图片，点击“创建周报”。创建成功会返回任务看板；进入刚创建的任务，点击“开始生成”。创建与启动是两个操作。

## 2. 查看 Writer 与 Review

在工作台观察工作流事件，等待 Writer 输出、Review 审核以及后续状态变化。Review 可能要求修订或补充材料，模型响应不会保证一次通过。

检查周报是否包含“本周完成”“进行中”“风险与阻塞”“下周计划”“待确认事项”五段。报表联调应保留在进行中，测试环境不可用应进入风险与阻塞，未知恢复时间应进入待确认事项；不应出现输入中没有的负责人、完成比例或承诺日期。

需要定位问题时打开 `/tasks/{taskId}/trace`，其中 `{taskId}` 替换为当前任务 ID。任务失败时检查事件和 Trace；健康检查正常不代表模型端点和模型响应正常。

## 3. 提交人工反馈

等待工作流进入人工处理状态后，在反馈框输入以下内容并点击“发送”：

```text
补充一条新事实：本周已完成看板空状态文案评审。
请将它写入“本周完成”。报表联调仍在进行中，测试环境恢复时间仍待确认。
请保留其他事实，不增加负责人、日期或完成比例。
```

等待后台处理完成，再检查版本列表出现新版本，且新版本包含新增事实。提交反馈被接受仅表示开始处理，不代表模型已经成功生成新版本；运行中或已有活动操作时需等待。

切换到反馈前的版本，确认旧版正文未被覆盖；再切回新版，确认原有阻塞和待确认事项仍然保留。

## 4. 确认并下载

事实核对完成且工作流允许确认时，点击审核事件中的“确认最终周报”，等待任务状态变为 `completed`。确认受任务状态和 Review 结果约束，详见[接口说明](api.md)。

选择最新版本，点击“下载 Markdown”，打开下载文件核对中文正文和五个段落。再选择反馈前的版本重新下载，核对文件内容对应所选版本，且不包含后来补充的空状态文案评审。下载针对当前选中版本；完成任务后仍可查看和下载历史版本。

## 5. 可选图片演示

另建一个任务，使用上面的虚构项目记录。自行制作仅含下列合成文字的 PNG、JPEG 或 WebP 图片，创建时上传：

```text
研发看板演示数据
接口测试通过：18 项
联调状态：进行中
```

在工作记录中补充“图片是本周测试看板，测试通过数量以图中信息为准”，不要在备注里重复 18 项。启动后检查模型能否从图片提取该独有数字，且没有把进行中的联调写成已完成；检查版本对应的图片预览。

如果 Review 请求补充材料，再制作一张将测试通过数量改为 24 项的合成图片，通过等待材料时的补图入口选择图片，填写“更新后的演示测试看板，以此图作为最新依据”，点击“上传材料”。等待重新理解、编写和审核后，检查新版本使用更新后的事实，旧版本正文和图片引用保持不变。

只有等待材料时才执行补图；Review 未请求材料时可完成普通图片流程，无需强行制造等待状态。反馈框的附件会进入审核会话，需要图片持久化为材料和版本引用时应使用补图入口。

## 完成检查

- 文字任务经历生成、审核、人工反馈、新版本、最终确认和下载。
- 新旧版本分别对应反馈前后的事实，下载内容与所选版本一致。
- 如演示图片，独有事实来自图片；如进入补图流程，新旧版本的图片引用相互隔离。
- 演示记录只反映本次实际经过的步骤，未执行的可选流程不标记为已验收。
- 演示产生的数据留在本地；公开仓库不附带数据库、个人案例、真实模型配置或密钥。
